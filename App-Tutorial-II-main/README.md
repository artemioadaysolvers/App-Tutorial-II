Tutorial para App Móviles II 

Tutorial para desarrollar una aplicación móvil que permite realizar simulaciones de Monte Carlo y visualizar sus resultados mediante componentes gráficos nativos del dispositivo utilizando React Native. Está desarrollada en TypeScript con JSX y TSX e incorpora una base de datos para almacenar las simulaciones realizadas, además de un sistema de inicio de sesión con autenticación mediante Google Cloud. El código fuente se aloja en GitHub y se utiliza GitHub Actions para automatizar los procesos de despliegue. Asimismo, el tutorial enseña a utilizar GitHub Desktop para administrar el repositorio y Android Studio para compilar la aplicación en un apk..
